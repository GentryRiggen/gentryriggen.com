# Frozen: the 1.0 sim and Titanic

A verbatim copy of `lib/shipwreck/sim` and `lib/shipwreck/ships` as of Shipwreck
1.0.0 (commit e5fd6da4), for `../titanicGolden.test.ts` only. That test runs the
Titanic through this copy and the current sim on the same machine and requires
identical tracks. Never edit, format or lint these files: changing them would
hide a change to the Titanic.
